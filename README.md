# Поиск фильмов (web_developer_filmsearch_melekhin)

Это веб-приложение для поиска и просмотра информации о фильмах. Пользователи могут искать фильмы, фильтровать их по различным критериям и просматривать подробную информацию о каждом фильме.

## ✨ Основные возможности

- **Поиск фильмов:** Поиск по названию.
- **Списки фильмов и сериалов:** Раздельные страницы для фильмов и сериалов.
- **Слайдер:** Динамический слайдер с популярными фильмами на главной странице.
- **Страница фильма:** Подробная информация о фильме, включая рейтинг, год выпуска и описание.
- **Переключатель темы:** Возможность переключения между светлой и темной темами.
- **Адаптивный дизайн:** Корректное отображение на мобильных устройствах и десктопах.

## 🛠️ Технологии

- **Frontend:** HTML, CSS, JavaScript
- **Сборка:** [Vite](https://vitejs.dev/)
- **Тестирование:** [Jest](https://jestjs.io/)

## 🚀 Установка и запуск

1.  **Клонируйте репозиторий:**

    ```bash
    git clone https://github.com/Alereee/Web_Developer_FilmSearch_Melekhin.git
    ```

2.  **Перейдите в директорию проекта:**

    ```bash
    cd Web_Developer_FilmSearch_Melekhin
    ```

3.  **Установите зависимости:**

    ```bash
    npm install
    ```

4.  **Запустите проект в режиме разработки:**
    ```bash
    npm run dev
    ```
    Проект будет доступен по адресу `http://localhost:5173` (порт может отличаться).

## 🧪 Тестирование

Для запуска тестов выполните команду:

```bash
npm test
```
